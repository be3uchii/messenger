Вставьте ссылку на страницу с сериалом
Как это работает: страница загружается через несколько CORS-прокси, из HTML вычленяются все iframe-плееры и прямые видео-ссылки (.m3u8, .mp4). Показываются все найденные варианты — кликни на любой для просмотра.
Вставьте прямую ссылку на видеофайл
Где взять ссылку: открой страницу с сериалом → F12 → Network → фильтр "m3u8" или "mp4" → скопируй URL нужного запроса.

Поддерживается: .m3u8 (HLS), .mp4, .webm, .mkv, .ogg — любые прямые ссылки на видео.
Вставьте HTML-код плеера или embed-код
Где взять: на странице с сериалом → F12 → Elements → найди <iframe> внутри блока плеера → скопируй весь тег.

Или на странице просмотра нажми ПКМ → "Просмотр кода страницы" (Ctrl+U) → Ctrl+F → ищи "iframe" или "player".

Service Worker — перехватывает все сетевые запросы страницы и блокирует рекламные домены до того, как они загрузятся. Работает пока открыта вкладка.

DOM-блокировки — каждую секунду сканируют страницу и удаляют рекламные элементы, попапы, оверлеи.

Защита браузера — перехватывает системные API, которые используются для открытия рекламы.

Сайт без рекламы

Открывает любой сайт во встроенном окне с максимальной блокировкой:
• Все попапы и всплывающие окна заблокированы
• Оверлеи и перекрывающие видео блоки удаляются
• Редиректы на рекламные сайты перехватываются
• Cookie-баннеры скрываются
• Баннерная реклама по классам и id убирается

⚠️ Ограничение: некоторые сайты запрещают открытие в iframe (X-Frame-Options). В таком случае используйте вкладки 1 или 2.
